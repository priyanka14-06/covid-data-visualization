# COVID-19 Data Visualization Story 🌍📊

An end-to-end data analysis and interactive visualization project exploring the global impact of COVID-19, built using real-world data from **Our World in Data**.

## 📌 Overview
This project analyzes COVID-19 case, death, and vaccination trends across countries and presents the findings as an interactive data storytelling experience using **Python and Plotly**.

## ❓ Questions Answered
- Which countries were most affected by COVID-19 (top cases)?
- How did different waves of the pandemic progress over time?
- How did vaccination rollout vary across countries?
- Is there a relationship between vaccination rates and death rates?

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, Plotly, NumPy
- **Environment:** Jupyter Notebook
- **Output:** Interactive standalone HTML charts

## 🔄 Workflow
1. **Data Collection** – Sourced real-world COVID-19 data from Our World in Data
2. **Data Cleaning** – Handled missing values, formatted dates, filtered relevant countries/metrics
3. **Exploratory Analysis** – Identified trends in cases, deaths, and vaccinations
4. **Visualization** – Built interactive Plotly charts for each key question
5. **Storytelling** – Structured insights into a clear, narrative-driven format

## 📈 Visualizations
| Chart | Description |

| `chart1_top_cases.html` | Top countries by total COVID-19 cases |

## 🚀 How to Run
1. Clone the repository
   ```bash
   git clone https://github.com/priyanka14-06/covid-data-visualization.git
   ```
2. Open `covid_project.ipynb` in Jupyter Notebook to view the full analysis
3. Open any of the `.html` files directly in a browser to explore individual interactive charts
